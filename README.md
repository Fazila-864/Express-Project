# Product & Category REST API

A simple and professional **RESTful API** built with **Node.js and Express.js** for managing products and categories. The APIs were tested and verified using **Postman**.

## 📌 Project Overview

This project provides backend APIs for managing **Categories** and **Products** through RESTful API endpoints.

The project is built using Express.js and demonstrates how to create and test backend APIs for basic CRUD operations.

## 🚀 Features

* Category CRUD operations
* Product CRUD operations
* RESTful API endpoints
* JSON request and response handling
* Express.js routing
* API testing with Postman
* Error handling
